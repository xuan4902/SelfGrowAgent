# SelfGrowAgent 汇报演示

> 一句话：**把「我想学 X」变成「可诊断、有计划、有练习、有反馈、能坚持」的成长闭环**。
> 适用场景：大赛答辩 / 项目汇报 / 录屏演示。全程离线可用（Mock 双模，无需 API Key）。

---

## 0. 演示前准备

```bash
pip install -e ".[engine]"                        # 引擎依赖（langgraph + anthropic SDK）
python -m unittest discover -s tests -v           # 冒烟：测试全绿再开演（当前 34 用例）
```

**一键演示命令（推荐，确定性输出，适合录屏）：**

```bash
python -m selfgrow.cli.main --mode auto
```

可自定义诉求与学员 ID：

```bash
python -m selfgrow.cli.main --mode auto \
  --goal "我想提升向上管理，尤其想学会怎么跟老板汇报" --learner demo_01 --db :memory:
```

> 有 `ANTHROPIC_API_KEY` 时自动切真 Claude；无则用确定性 Mock——**两种方式演示效果一致**，
> 评审无需担心网络与密钥。

---

## 1. 三幕演示脚本（对应实跑证据见 `artifacts/demo_auto_run.txt`）

### 第 1 幕 · 诊断与规划（约 30 秒）

> 🔮 占卜师把模糊诉求拆成 6 项子能力 → 12 题情景测评 → 生成能力雷达 → 定位薄弱点 → 🗺️ 制图师排出 2 周闯关路线。

**演示动作**：打出诉求一行，随后逐条展示测评题，停顿一句「12 道情景题，每道都是真实职场困境」。

**实跑证据（摘录）**：

```
🎯 诉求：我想提升向上管理，尤其想学会怎么跟老板汇报
  1. 领导周五下班前说『下周一就要上线新版功能』。你会？
     (1) 直接答应，周末加班硬扛
     (2) 立刻澄清交付标准、验收方式和最晚时间，说明现实约束
     ...
（测评后）最需要修炼的是「管理期待」→ 路线图：W1 管理期待 → W2 应对反馈
```

**对应能力**：① 任务理解 ｜ ② 计划生成 ｜ ⑦ 结果验证

### 第 2 幕 · 学习与演练（约 1 分钟，核心看点）

> 📖 讲师从 RAG 知识库检索干货讲解（**知识增强**）→ ⚔️ 陪练武士开副本与 NPC 多回合对线（**多轮交互**）→ 📜 史官引导复盘沉淀（**上下文记忆**）。

**演示动作**：指着「从知识库翻出了干货」强调 RAG；进入副本时强调「这是沉浸式情景，NPC 会追问，你边说它边评」。

**实跑证据（摘录）**：

```
📖 第 1 关「管理期待」讲解
好，这周我们修炼「管理期待」。为师从知识库翻出了干货：
预期管理三原则｜原则二：过程中用「偏差提前同步」；预期管理三原则｜为什么要管理预期。

⚔️ 副本《不合理工期保卫战》 回合 1/2
  NPC：「这个报告下周三前必须交，就 3 天，能不能干？」
  ⚔️ 副本《不合理工期保卫战》 回合 2/2
  NPC：「3 天不行？你手头还有什么事？」
（回合间你的每一次回应都会触发即时评分与磨刀建议）
```

**对应能力**：⑤ 知识增强 RAG ｜ ③ 多轮交互 ｜ ④ 工具调用 ｜ ⑥ 上下文记忆

### 第 3 幕 · 复测与毕业（约 30 秒，亮点在「动态调整 + 量化成长」）

> 到达周中检查点自动复测（6 题）→ 雷达对比 → 🗺️ 重排剩余关卡 → 通关战报给出 **量化成长**。

**演示动作**：一句「学到了中途，系统会停下来重新考你，验证真的进步了没有」；展示雷达前后对比与「已提升 / 仍待修炼」。

**实跑证据（摘录）**：

```
【入关时】                      【通关后】
  管理期待  ██········  L1       管理期待  ██████████  L5
  争取资源  ██········  L1       争取资源  ██████████  L5
  向上沟通  ██········  L1       向上沟通  ██████████  L5

— 成长维度 —
✅ 已提升：管理期待、争取资源、向上沟通
🔸 仍待修炼：应对反馈（建议开启下一轮副本）

— 工具调用留痕（评审证据） —
  build_mindmap×1、generate_assessment×2、get_scenario×1、save_record×11、search_knowledge×2
```

**对应能力**：⑦ 结果验证 ｜ ② 计划生成（动态调整） ｜ ⑥ 上下文记忆

## 2. 官方 7 项 Agent 能力 · 评审对照表

| 官方能力点 | 作品实现 | 演示中可见证据 |
|---|---|---|
| ① 任务理解 | 🔮 模糊诉求 → 目标拆解 → 情景测评 | 第 1 幕：诉求一行 + 6 子能力拆解 |
| ② 计划生成 | 🗺️ 按薄弱点排周路线；**复测后动态重排** | 第 1 幕路线图 + 第 3 幕重排 |
| ③ 多轮交互 | `interrupt()/Command(resume=)`：逐题作答、讲师追问、NPC 多回合对线 | 第 2 幕：回合 1/2 → 回合 2/2 |
| ④ 工具调用 | 检索/出题/取场景/雷达/思维导图/落库，全程留痕 | 战报「工具调用留痕」区块 |
| ⑤ 知识增强 RAG | 10 篇自撰语料分块向量化，检索 top-k 注入讲解 | 第 2 幕「从知识库翻出了干货」 |
| ⑥ 上下文记忆 | checkpointer（thread_id=learner_id）断点续学 + SQLite 历史对比 | 复测「已提升 vs 基线」对比 |
| ⑦ 结果验证 | 基线 vs 复测雷达对比 → 量化成长战报 | 第 3 幕雷达前后对比 + XP/等级 |

**可现场追问的纵深**：断点续学（中途 `Ctrl+C` 退出再重跑同 `--learner` 可继续）、
工具留痕 JSON（`state["tools_called"]`）、能力框架换域不改代码（`data/frameworks/*.json`）。

## 3. 两种演示形态

| 形态 | 命令 | 适合 |
|---|---|---|
| **自动演示**（脚本作答，全自动） | `--mode auto` | 录屏、评委快速看完整闭环 |
| **真人交互**（你实时扮演学习者） | `--mode interactive` | 答辩现场，评委提问你来作答 |

> 语音对话入口（`--mode voice`）为后续增强：语音输入（whisper 离线）+ 语音朗读（edge-tts/SAPI）。
> 已在 Windows 上验证单次全流程可跑通，多流程稳定性仍在打磨——**正式演示以 auto/interactive 为准**。

## 4. 合规与边界（演示结束语，必读）

> 「本系统**全部使用自建模拟数据**，不收集、不保存任何真实学生个人信息；
> 所有输出为**可替换学校/专业评价的辅助学习建议**，不替代正式测评或专业咨询；
> 关键结论均有人工确认机制。」

详细约束见 `docs/data_compliance.md`、`docs/boundary_risks.md`。

## 5. 演示话术速记（60 秒版）

1. 「这是一个教育 Agent：**诊断 → 规划 → 学 → 练 → 复盘 → 复测 → 毕业**的完整闭环。」
2. 「五个角色各司其职：占卜师拆解、制图师排线、讲师教方法、陪练武士带实战、史官记成长。」
3. 「关键在**可验证**：不是我说你进步了，是复测雷达对比给你看进步了多少。」
4. 「全程离线、全中文、全部自建数据，随时能跑。」

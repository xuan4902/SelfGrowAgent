# SelfGrowAgent 汇报演示

> 一句话：**把「我想学 X」变成「可诊断、有计划、有练习、有反馈、能坚持」的成长闭环**。
> 适用场景：大赛答辩 / 项目汇报 / 录屏演示。全程离线可用（Mock 双模，无需 API Key）。
> 三幕脚本的实跑证据见 `artifacts/demo_auto_run.txt`（最新代码一键生成），Web 视觉小说界面见 `artifacts/web_vn_*.png`。

---

## 0. 演示前准备

```bash
pip install -e ".[engine]"                        # 引擎依赖（langgraph + anthropic SDK）
python -m unittest discover -s tests -v           # 冒烟：95 用例全绿再开演
```

**一键演示命令（推荐，确定性输出，适合录屏）：**

```bash
python -m selfgrow.cli.main --mode auto
```

可自定义诉求与学员 ID：

```bash
python -m selfgrow.cli.main --mode auto \
  --goal "我想提升向上管理，尤其想学会怎么跟老板汇报" --learner demo_01 --db :memory:
```

**Web 视觉小说界面（推荐现场演示，文字冒险/VN 风格）：**

```bash
pip install -e ".[web]"
python -m selfgrow.web.app          # 打开 http://127.0.0.1:8000
```

> 有 `ANTHROPIC_API_KEY` 时自动切真 Claude；无则用确定性 Mock——**两种方式演示效果一致**，
> 评审无需担心网络与密钥。

## 1. 三幕演示脚本（对应实跑证据见 `artifacts/demo_auto_run.txt`）

### 第 1 幕 · 诊断与规划（约 30 秒）

> 🔮 占卜师把模糊诉求拆成子能力 → **AI 逐题自适应测评**（10 题基线，答错当场追问同维度更难的题）→ 生成能力雷达 → 定位薄弱点 → 🗺️ 制图师排出 2 周闯关路线。

**演示动作**：打出诉求一行，随后逐题展示测评。强调「这不是写死题库——每道题都是 AI 根据你上一题作答现场生成，答错会加深难度追问」；停顿一句「10 道情景题，每道都是真实职场困境」。

**实跑证据（摘录）**：

```
🎯 诉求：我想提升向上管理，尤其想学会怎么跟老板汇报
  1. 你被要求向领导汇报上周工作。你会怎么开头？
     (1) 从上周一早上的第一件事开始讲
     (2) 先说最关键的结果和结论，再展开过程和细节
     ...
  （第 3 题，答错后自动加深难度）
  这一题是本座特意加的难度考校：上一题你答得不太稳，换个更刁钻的再试试。
（测评后）最需要修炼的是「管理期待」→ 路线图：W1 管理期待 → W2 应对反馈
```

**对应能力**：① 任务理解 ｜ ② 计划生成 ｜ ⑦ 结果验证

### 第 2 幕 · 学习与演练（约 1 分钟，核心看点）

> 📖 讲师从 RAG 知识库检索干货讲解（**知识增强**）→ ⚔️ 陪练武士用**动态场景引擎**开副本：AI 按维度+学员背景现场生成 BOSS 人设 / 办公环境 / 利害压力，多回合对线（**多轮交互**）→ 📜 史官引导复盘沉淀（**上下文记忆**）。

**演示动作**：指着「从知识库翻出了干货」强调 RAG；进副本时指着 BOSS 卡强调「这个老板、这个会议室、这条压力条全是 AI 为这一关现生成的」；回合推进时强调「NPC 会追问，你边说它边评」。

**实跑证据（摘录）**：

```
📖 第 1 关「管理期待」讲解
好，这周我们修炼「管理期待」。为师从知识库翻出了干货：
预期管理三原则｜原则二：过程中用「偏差提前同步」；预期管理三原则｜为什么要管理预期。

⚔️ 副本《不合理工期保卫战》 回合 1/2
  BOSS：直属领导（李总）（施压试探）· 急性子、结果导向，但讲道理，喜欢『带方案来谈』的下属
  环境：周二上午的会议室，玻璃窗外另一组人正在赶工，领导的手机不时震动。
  压力：███░░ 领导当着全组的面下 deadline，当场讨价还价需要勇气与话术
  利害：季度里程碑 + 你在领导心中『靠谱/能扛事』的标签
  NPC：「这个报告下周三前必须交，就 3 天，能不能干？」
（回合间你的每一次回应都会触发即时评分与磨刀建议；压力条随回合上涨）
```

**对应能力**：⑤ 知识增强 RAG ｜ ③ 多轮交互 ｜ ④ 工具调用 ｜ ⑥ 上下文记忆

### 第 3 幕 · 复测与毕业（约 30 秒，亮点在「动态调整 + 量化成长」）

> 到达周中检查点自动复测（3 题，聚焦薄弱维度）→ 雷达对比 → 🗺️ 重排剩余关卡（第 2 周由「管理期待」重排为复测暴露的「应对反馈」）→ 通关战报给出 **量化成长**。

**演示动作**：一句「学到了中途，系统会停下来重新考你，验证真的进步了没有」；展示雷达前后对比与「已提升 / 仍待修炼」。

**实跑证据（摘录）**：

```
【入关时】                      【通关后】
  管理期待  ██········  L1       管理期待  ██████████  L5
  争取资源  ██········  L1       争取资源  ██████████  L5
  向上沟通  ██········  L1       向上沟通  ██████████  L5

— 成长维度 —
✅ 已提升：管理期待、争取资源、向上沟通
🔸 仍待修炼：应对反馈（建议开启下一轮副本）

— 闯关路线（本周期） —
  ✔ W1 管理期待 → 突破至 L2：接任务三问：交付物？验收标准？最晚时间？
  ✔ W2 应对反馈 → 突破至 L2：练习先听完再回应，不做防御性反驳

— 工具调用留痕（评审证据） —
  build_mindmap×1、generate_question×13、generate_scenario×2、save_record×11、search_knowledge×2
```

**对应能力**：⑦ 结果验证 ｜ ② 计划生成（动态调整） ｜ ⑥ 上下文记忆

## 2. Web 视觉小说界面（本次版本的重头戏）

前端改造成**文字冒险 / 视觉小说（VN）**，去掉「AI 味」，营造「闯关打副本」的体验（截图见 `artifacts/web_vn_*.png`）：

| 交互 | 呈现 |
|---|---|
| 测评 | 打字机旁白 + 4 个 `▼` 选项，答错自动加难度追问 |
| 对线副本 | **BOSS HUD**：名牌+人设、压力条 `3/5→4/5`、回合推进、自由输入回应 |
| 进度 | 顶部 HUD：XP 条 + 等级徽章 + 旅程点（诊断 ▸ 规划 ▸ W1..Wn ▸ 毕业） |
| 通关 | 结算战报 + 成长雷达前后对比 + 闯关路线回顾 + 工具留痕抽屉 |

会话中途刷新（`?sid=`）SSE 重放历史，从当前单题场景无缝续玩。截图：

## 3. 官方 7 项 Agent 能力 · 评审对照表

| 官方能力点 | 作品实现 | 演示中可见证据 |
|---|---|---|
| ① 任务理解 | 🔮 模糊诉求 → 目标拆解 → 情景测评 | 第 1 幕：诉求一行 + 子能力拆解 |
| ② 计划生成 | 🗺️ 按薄弱点排周路线，每周含里程碑/行动清单/关联副本；**复测后动态重排** | 第 1 幕路线图 + 第 3 幕重排（W1→W2 换维） |
| ③ 多轮交互 | `interrupt()/Command(resume=)`：逐题作答、讲师追问、NPC 多回合对线 | 第 2 幕：回合 1/2 → 回合 2/2；测评逐题 interrupt×13 |
| ④ 工具调用 | 逐题出题/动态场景/检索/落库/思维导图，全程留痕 | 战报「工具调用留痕」区块（generate_question×13 等） |
| ⑤ 知识增强 RAG | 10 篇自撰语料分块向量化，检索 top-k 注入讲解 | 第 2 幕「从知识库翻出了干货」 |
| ⑥ 上下文记忆 | checkpointer（thread_id=learner_id）断点续学 + SQLite 历史对比 | 复测「已提升 vs 基线」对比 |
| ⑦ 结果验证 | 基线 vs 复测雷达对比 → 量化成长战报（XP/等级） | 第 3 幕雷达前后对比 + XP 100 / L3 |

**可现场追问的纵深**：断点续学（中途 `Ctrl+C` 退出再重跑同 `--learner` 可继续）、
工具留痕 JSON（`state["tools_called"]`）、能力框架换域不改代码（`data/frameworks/*.json`）、
AI 逐题自适应出题（答错加深难度追问）、动态场景引擎（BOSS 人设/环境/压力/利害现生成）。

## 4. 三种演示形态

| 形态 | 命令 | 适合 |
|---|---|---|
| **自动演示**（脚本作答，全自动） | `--mode auto` | 录屏、评委快速看完整闭环 |
| **真人交互**（你实时扮演学习者） | `--mode interactive` | 答辩现场，评委提问你来作答 |
| **Web 视觉小说**（浏览器点选/输入） | `python -m selfgrow.web.app` | 现场展示游戏化体验 + 截图证据 |

> 语音对话入口（`--mode voice`）已随仓库一并提交：语音输入（whisper 离线）+ 语音朗读（edge-tts/SAPI）。
> 稳定性仍在打磨，**正式演示以 auto/interactive/Web 为准**。

## 5. 合规与边界（演示结束语，必读）

> 「本系统**全部使用自建模拟数据**，不收集、不保存任何真实学生个人信息；
> 所有输出为**可替换学校/专业评价的辅助学习建议**，不替代正式测评或专业咨询；
> 关键结论均有人工确认机制。」

详细约束见 `docs/data_compliance.md`、`docs/boundary_risks.md`。

## 6. 演示话术速记（60 秒版）

1. 「这是一个教育 Agent：**诊断 → 规划 → 学 → 练 → 复盘 → 复测 → 毕业**的完整闭环。」
2. 「五个角色各司其职：占卜师拆解、制图师排线、讲师教方法、陪练武士带实战、史官记成长。」
3. 「关键在**可验证**：不是我说你进步了，是复测雷达对比给你看进步了多少。」
4. 「全程离线、全中文、全部自建数据，随时能跑；前端是游戏化的文字冒险，AI 逐题出题、对线有 BOSS 压力。」

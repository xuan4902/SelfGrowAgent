环境Python 3.10+；跨平台（Windows / Linux / macOS 均可运行）

  • pip install -e ".[engine]" —— LangGraph + anthropic SDK（引擎层）

  • CLI 自动演示：python -m selfgrow.cli.main --mode auto
  • CLI 真人交互：python -m selfgrow.cli.main --mode interactive
  • Web 视觉小说界面：python -m selfgrow.web.app → http://127.0.0.1:8000

④

失败与异常分支可解释

检查要求 · 说明调用失败、信息不足、高风险判断时的处理方式
✅ 完成
每个异常都有明确兜底，学习循环永不卡死——双模行为一致，是演示稳定性的根基。
调用失败LLM 返回非法 JSON → try/except 回退确定性题库 / 场景库（tools.py:78-84、:144-150）；真模型与 Mock 行为一致，循环永不卡死
信息不足讲师人设「答不上来就明说」；教学原则「给提示不给答案」——附错因分析、同类训练
高风险判断人工确认机制：测评作答 / 学习动作 / 对线回应 / 复盘反思均由学习者亲自决策；关键结论须人工确认
网络依赖真模型调用失败自动落回确定性 Mock，演示与测试不中断、不受网络波动影响
依据docs/boundary_risks.md §3 人工确认机制 · §4 风险与缓解；src/selfgrow/agents/tools.py 失败回退实现

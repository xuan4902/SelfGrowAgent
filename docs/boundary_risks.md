# 使用边界与风险说明（对应赛事「使用边界」条款）

## 1. 产品定位声明

SelfGrowAgent 是**辅助学习工具**，为成年学习者提供个性化自驱学习的引导与模拟练习。

**产品输出不构成、也不替代**：

- ❌ 学校 / 培训机构 / 企业的正式能力测评与考核结论
- ❌ 职业咨询师、心理咨询师、教练的专业评估与诊断
- ❌ 任何录用、晋升、评分的决策依据
- ❌ 医疗、法律等专业领域建议

所有测评雷达、等级、XP、战报均为**产品内的游戏化成长反馈**，帮助学习者自我观察与练习，
不代表真实世界的能力认证。

## 2. 边界声明（CLI 战报末尾自动输出）

```
本结果为辅助学习建议，不替代正式测评、学校/机构评价或专业心理咨询。
全部数据为自建模拟数据，不涉及真实个人信息；如需接入真实学习者数据，请先完成合规评审。
```

## 3. 人工确认机制

产品遵循「AI 辅助、人工决定」原则，设计了多个人工确认点：

| 环节 | 人工确认内容 |
|---|---|
| 目标录入 | 学习者自主输入诉求，可随时修改 |
| 测评作答 | 每题由学习者亲自作答（auto 模式仅用于演示） |
| 学习动作 | 选择「继续问 / 去演练 / 复盘」由学习者决定 |
| 演练对线 | 每回合回应均由学习者输入，NPC 不替学习者做决定 |
| 复盘反思 | 反思文本由学习者亲笔书写 |
| 动态调整 | 复测后调整由系统建议、学习者知情 |

## 4. 风险与缓解

| 风险 | 说明 | 缓解措施 |
|---|---|---|
| 认知偏差 | AI 生成的讲解/评分可能包含错误或偏见 | 语料基于公开方法论原创撰写；讲师人设明确「答不上来就明说」；结论均有测评依据 |
| 教育评价误用 | 战报被误读为正式能力认证 | 边界声明、产品定位声明、人工确认机制 |
| 过度依赖 | 学习者把模拟练习等同于真实能力 | 战报标注「仍待修炼」维度；建议结合真实工作实践与上级反馈 |
| 数据隐私 | 若接入真实数据可能泄露 | 当前全模拟数据；接入清单见 data_compliance.md |
| 技术局限 | Mock 评分（无 Key 时）为关键词启发式，精确度有限 | 双模设计：配置 ANTHROPIC_API_KEY 即切换真模型打分；测试保证确定性 |
| 网络依赖 | 真模型模式依赖网络与 Key | Mock 兜底零依赖，演示不中断 |

## 5. 年龄与场景适配

- 目标人群：20–35 岁职场成年人（职业教育 / 个性化学习场景）。
- 若面向未成年人使用，需监护人知情同意，且测评内容不涉及敏感个人信息。
